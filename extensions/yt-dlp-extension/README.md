# YT-DLP Extension

A Node.js extension for yt-dlp functionality built with TypeScript and bundled using esbuild.

## Prerequisites

-   **Node.js** (version 20 or higher)
-   **npm** (comes with Node.js)

## Installation

1. Navigate to the project directory
2. Install dependencies:

```bash
npm install
```

## Building the Distribution

To build the distribution, run:

```bash
npm run build
```

This will compile TypeScript source files and generate a minified CommonJS bundle at `dist/index.cjs`.
